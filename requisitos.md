# Documento de Requisitos
## 1. Introdução
O sistema de Achados e Perdidos da Escola tem como objetivo facilitar a comunicação entre quem perdeu e quem encontrou algum objeto na escola.

## 2. Objetivo
Criar um sistema onde os alunos possam **cadastrar, procurar e encontrar objetos perdidos**, sem precisar ficar procurando pela escola.

## 3. Requisitos Funcionais
- **RF01:** Fazer cadastro e login.
- **RF02:** Cadastrar objetos encontrados, com descrição, foto e local.
- **RF03:** Cadastrar objetos perdidos.
- **RF04:** Ver objetos perdidos e encontrados.
- **RF05:** Pesquisar objetos por palavras-chave.
- **RF06:** Marcar um objeto como devolvido.
- **RF07:** Mostrar a data do registro.

## 4. Requisitos Não Funcionais
- **RNF01:** O sistema deve ser simples e fácil de usar.
- **RNF02:** Deve funcionar em celulares e computadores.
- **RNF03:** Deve responder rapidamente.
- **RNF04:** Os dados dos usuários devem ser protegidos.
- **RNF05:** Deve ficar disponível para acesso sempre que possível.
- 
## 5. Regras de Negócio
- Apenas quem cadastrou um objeto encontrado pode marcá-lo como devolvido.
- Objetos que ficarem muito tempo sem atualização podem ser revisados.

Nesta etapa serão feitos:
